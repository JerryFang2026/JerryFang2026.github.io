Reading context

The statistical methodology (t-tests, ANOVA, chi-square, regression, survival analysis) remains sound, but the 2016 Python, pandas and statsmodels code examples use APIs that have changed and may not run under current versions; use the second edition for updated code. Do not rely on this for current Python syntax, package import patterns, or data-input workflows.

A later edition (2nd ed., Springer 2022, ISBN 978-3-030-97370-4) supersedes this with reworked Python, data-input and visualisation chapters; the author's GitHub repository provides companion code.
