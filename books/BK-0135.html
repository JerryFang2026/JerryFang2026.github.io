Elementary Linear Programming with Applications

Introduces linear programming with applications. Contents include a review of linear algebra, Gauss-Jordan reduction, Karmarkar's algorithm, microcomputer software, and the SMPX program.

Best for: Linear algebra review, optimization algorithms, and computational linear programming tools.
